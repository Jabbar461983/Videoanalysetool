# Testanleitung: Playlist automatisch füllen und einzeln exportieren

1. Video öffnen, einige Szenen taggen (z. B. 2 Tore, 1 Fehler), optional Spieler zuordnen.
2. Tab «Playlist» → **«Automatisch füllen …»**.
3. **Was?** Tags anklicken (mehrere möglich) oder Schnellauswahl «Alle Tore», «Alle Bullys», «Strafen», «Schüsse und Paraden».
4. **Wer?** Team oder einzelnen Spieler wählen (zweiter Filter). **Wo?** alle Videos oder nur eines (z. B. 2. Halbzeit).
5. Die Vorschau zeigt Anzahl und Dauer; einzelne Szenen mit dem Haken abwählen.
6. «Nach Thema gruppieren» fügt vor jedem Thema eine Titelfolie ein (Kicker = Spieler/Team, Titel = Thema, Untertitel = Anzahl).
7. Ziel: «Neue Playlist anlegen» (Name wird vorgeschlagen) oder «Am Ende von … anhängen». Bereits vorhandene Szenen werden übersprungen.
8. «Übernehmen». Die Playlist lässt sich danach wie gewohnt ordnen, kürzen und ergänzen (sie bleibt nicht mit dem Filter verbunden).
9. Kurzweg: Tab «Setup» → beim Spieler im Kader **«Alle Szenen»**.
10. Export: Tab «Export» → Playlist im Auswahlfeld wählen → «Als MP4 exportieren». **«Alle Playlists einzeln exportieren»** schreibt jede Playlist als eigenes MP4 (Ordner wählen, wo der Browser es erlaubt; sonst Downloads).
